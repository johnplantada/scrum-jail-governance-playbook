# Demo evidence

Product-surface features require evidence generated by the Human-dispatched
`demo-evidence.yml` workflow on the exact current PR head SHA. Internal work may instead use
an acceptance line already present on the issue.

The Software Implementer links the PR and evidence run in an ordinary brokered comment.
The Commercial Planner independently reads the current evidence and acceptance criteria.
If every criterion is met, it posts one issue comment beginning `[DEMO]` containing:

```text
accepted: true
item: OWNER/ORG#N
acceptance_digest: <sha256 of normalized acceptance lines>
pr: OWNER/PRODUCT#M
head_sha: <40-character current head>
evidence_run: <run URL bound to that head>
```

Then it moves the owned feature to `Awaiting Deploy`. `pm-gh.sh done --demo <comment-url>`
re-reads the exact issue comment and issue acceptance digest. A stale, unrelated, malformed,
or incompletely read comment is not evidence.

This skill never dispatches a workflow, merges, deploys, spends, or treats a green check as
Human authorization.
